# الإعدادات

كل خيار، وما يغيّره، ومتى تلجأ إليه.

## اللغات

| الخيار           | النوع      | الافتراضي           | ما يفعله                                       |
| :--------------- | :--------- | :------------------ | :--------------------------------------------- |
| `locales`        | `string[]` | —                   | كل لغة يبنيها هذا المشروع. مطلوب.              |
| `sourceLocale`   | `string`   | أول عناصر `locales` | اللغة التي تكتب بها. لا تُكتب على القرص أبدًا. |
| `pendingLocales` | `string[]` | `[]`                | تُصان وتُفحص، ولا تُشحن.                       |

## أين تذهب الأشياء

| الخيار          | النوع                       | الافتراضي                       | ما يفعله                                                                      |
| :-------------- | :-------------------------- | :------------------------------ | :---------------------------------------------------------------------------- |
| `outputDir`     | `string`                    | `"./zintl"`                     | حيث تُكتب الكتالوجات، من جذر المشروع.                                         |
| `catalogFormat` | `string \| (ctx) => string` | `<path>[.<func>].<locale>.json` | تسمية الكتالوجات. الرموز: `[locale] [path] [dir] [name] [func] [bId] [hash]`. |
| `metadataDir`   | `string`                    | `node_modules/.zintl`           | دفاتر المُصرِّف الخاصة. ليست مما تحرّره.                                      |

## محتوى وراء الشيفرة

| الخيار          | النوع                             | الافتراضي       | ما يفعله                                                                            |
| :-------------- | :-------------------------------- | :-------------- | :---------------------------------------------------------------------------------- |
| `assetsTarget`  | `(string \| AssetTargetConfig)[]` | `["md", "txt"]` | ملفات يتغير محتواها باللغة. الامتداد المجرد يعني `**/*.<ext>`.                      |
| `virtualAssets` | `boolean`                         | `false`         | تسليم الأصول المُوطَّنة عبر وحدات افتراضية بدل حلّ الاستيرادات إلى الأثر على القرص. |

الأصل المستهدَف **يُؤلَّف** لكل لغة، لا يُترجَم إلى الوجود. وإن كان الملف نفسه في كل اللغات، فلا تستهدفه.

وكيف يصل إلى المتصفح يتبع استيرادك لا الامتداد:

```ts
import text from "./about.txt?raw"; // المحتوى، مُدرَجًا في الكتالوج
import url from "./hero.webp"; // رابط المُحزِّم لأثر هذه اللغة
```

وكلاهما يتبع اللغة وقت التشغيل، فتبديل اللغة يعيد توجيه الاستيراد بلا إعادة تحميل.

## الصيانة

| الخيار                | النوع     | الافتراضي                             | ما يفعله                                                        |
| :-------------------- | :-------- | :------------------------------------ | :-------------------------------------------------------------- |
| `prune`               | `boolean` | `true`                                | إزالة مفاتيح الكتالوج متى لم يعد أي نص مصدر ينتجها.             |
| `similarityThreshold` | `number`  | `0.6`                                 | كم يجب أن يتشابه نص مُعدَّل ليحتفظ بترجمته. الأقل أكثر تسامحًا. |
| `verifyIntegrity`     | `boolean` | `true` عند البناء، `false` في التطوير | إفشال البناء عند ترجمة ناقصة.                                   |

> [!IMPORTANT]
> `verifyIntegrity` هو ما يجعل الترجمة الناقصة تُفشل بناءك بدل أن تُعرض فارغة. زينتل لا يملك رجوعًا إلى لغة المصدر بحكم التصميم — وهذا هو الفحص الذي يلتقط الثغرة قبل مستخدميك. ويشمل الأصول المُوطَّنة أيضًا: الأثر الفارغ ترجمةٌ ناقصة لها ملف بدل الجسد.

## ما يُعدّ نصًا قابلًا للترجمة

يُستخرج النص حين يبلغ **مصرفًا** — موضعًا يُعرف أن النص فيه مواجه للمستخدم. والمصارف تعلنها الأوجه، فما يستخرجه مشروعك ينبع من الأوجه النشطة فيه.

| الصيغة                  | تطابق                                 |
| :---------------------- | :------------------------------------ |
| `jsx:<element>:<attr>`  | خاصية JSX؛ و`*` لأي عنصر              |
| `html:attr:<attr>`      | خاصية في HTML أو في قالب SFC          |
| `dom:<receiver>:<prop>` | إسناد إلى خاصية                       |
| `obj:<binding>:<field>` | حقل في كائن مُسمّى                    |
| `call:<fn>:<field>`     | حقل في كائن مُمرَّر إلى ذلك الاستدعاء |
| `tag:<fn>`              | قالب نصي موسوم يحمل ترميزًا           |

النص العادي في مستندات HTML وقوالب SFC وأبناء JSX لا يحتاج واصفًا — فهو نص في ترميز، وهذا وحده دليل.

ولا يوجد عمدًا **`obj:field:*`** افتراضي. فمطابقة اسم حقل على أي كائن لا تعرف شيئًا عن الكائن، فكان `{ label: "signup_click" }` يُستخرج كأي تسمية. سمِّ الكائن بدلًا من ذلك:

```ts
const ui = { home: { title: "Welcome" } }; // obj:ui:title
defineConfig({ title: "My site" }); //        call:defineConfig:title
```

استعمل `additionalTargets` لتضيف إلى ما تجده الأوجه النشطة، و`targets` الخاصة بوجه لتستبدل ما يسهم به ذلك الوجه.

## توسيعه

| الخيار              | النوع                 | ما يفعله                                   |
| :------------------ | :-------------------- | :----------------------------------------- |
| `facets`            | `(string \| Facet)[]` | تركيب سلوك إطار العمل والمُحزِّم والمحتوى. |
| `additionalTargets` | `string[]`            | إضافة واصفات مصارف دون استبدال أيٍّ منها.  |
| `multiplex`         | `boolean`             | مستند HTML لكل لغة. في Vite فقط.           |
| `debug`             | `string`              | تتبّع نظام فرعي في المُصرِّف.              |

وضبط خيار يخص وجهًا استبدلته خطأٌ فوري، لا إعداد لا يفعل شيئًا بصمت.
