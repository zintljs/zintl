# 术语表

本文档使用的词，以及它们在这里各自的含义。

## 本地化资源

内容随语言而变的文件，而不是组件里的字符串——由 `assetsTarget` 匹配，默认是 `.md` 和 `.txt`。

## 边界

从一个**信任锚点**可达的字符串集合。它会成为一个目录分块。以其内容的哈希（`b_<hash>`）标识，而不是以路径标识。

## 产物

Zintl 为**本地化资源**按语言写下的文件——`zintl/src/about.fr.txt` 就在 `src/about.txt` 旁边。它被创建为空文件，由人来撰写；绝不会从原文复制。

## 分块

边界在浏览器中的形态：打包器加载的单位。入口分块随页面到达，懒加载分块随需要它的路由到达，共享分块出现在两个入口重叠之处。

## 幽灵模式

源语言永远不会被写入磁盘。编译器依据提取清单将其虚拟化，并且只有当它是当前语言时才懒加载。

## 挂起语言

正在进行中的语言：它的目录会被维护和校验，但不会被发布。

## 目录

一个源文件在一种语言下的译文——位于 `outputDir` 中的一个 JSON 文件。这是译者编辑的东西。

## 缝合单元

真正的提取单位。模板字面量、JSX 片段与 HTML 会在提取前被缝合成逻辑片段，因此被标签拆开的句子仍是一个键。

## 切面

覆盖单一关注点的、可组合的编译器行为部件——一个框架、一个打包器、SSR、资源。在构造编译器时解析。

## 入口点

含有**顶层** `zintl()` 调用的文件，区别于嵌套在函数内部的调用。入口拥有一个分块。

## 殖民地

只能通过动态导入从某个入口到达的边界。它的字符串属于那个入口的世界，但随懒加载路由一同到达。

## 汇点

已知面向用户的字符串所处之地——标记中的文本、`alt`、对 `textContent` 的赋值。让字符串可翻译的是它抵达了汇点，而不是它看起来像不像散文。

## 管理器

为某个边界加载正确目录的生成代码。它会内联锚点所用的语言以便快速启动，并让其余语言保持懒加载。

## 令牌指令

引导编译器的注释——`@zintl-ignore`、`@zintl-target`、`@zintl-note`、`@zintl-pass`。参见[注释指令](/reference/comment-directives)。

## 多路展开

为每种语言构建一份 HTML 文档，各自固化那一种语言。仅限 Vite。

## 信任锚点

一次 `zintl(locale)` 调用——你的应用在此声明自己处于哪种语言。每个锚点都是独立的，各有自己的水合生命周期。

## 源语言

你书写所用的语言。永不写入磁盘，也永不用作回退。
